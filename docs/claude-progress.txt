# my-project - 进度跟踪

## 项目概述
将 OA 系统原前端 (ruoyi-vue-oa-ui, Vue 2 SPA) 的所有功能页面迁移到新前端 (jun_ui_sa_admin, sa-admin 框架)。
新前端使用 httpVueLoader 动态加载 .vue 文件，无需 webpack 构建。
迁移策略：直接复制原前端 .vue 文件，小改适配 loader 加载方式。

## 架构决策
- 加载方式：使用 httpVueLoader 加载 .vue 文件（非 iframe .html 方式）
- API 适配：创建兼容层将原前端 axios request 映射为新前端 sa.ajax
- 路由适配：将 Vue Router ($router.push) 映射为 sa_admin tab 机制
- 状态管理：创建轻量适配层替代 Vuex store
- 权限指令：在新前端全局注册 v-hasPermi / v-hasRole

## 规模统计
- 原前端：~149 个 .vue 组件，60+ 个 API 模块，14 个业务模块
- 新前端：~159 个 .vue + 31 个 .html 页面（部分需清理）
- 任务总数：52 个
