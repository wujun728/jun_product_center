# jun-oa-frontend-upgrade - 进度跟踪

## 项目概述

**项目名称：** jun-oa-frontend-upgrade
**创建时间：** 2026-04-13
**项目类型：** 前端升级（Vue 2 → Vue 3）

**目标：**
将原前端（ruoyi-vue-oa-ui，Vue 2.6 + Element-UI）的所有功能迁移到新前端（yudao-ui-admin-vue3，Vue 3.5 + Element-Plus + TypeScript），同时保持与后端（ruoyi-vue-oa，Spring Boot）的完全兼容。

**关键指标：**
- 原前端Vue文件：149个
- 新前端Vue文件：736个（需清理无效模块）
- 核心模块：系统管理、工作流、监控、文件管理、消息、知识库等
- 预计工期：8-12周（2-3名前端开发人员）

### API适配策略

**后端API格式：** RuoYi标准格式
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {}
}
```

**适配要点：**
1. 响应拦截器：统一处理code码（200=success, 401=unauthorized, 500=error）
2. Token管理：localStorage存储，请求头携带`Authorization: Bearer {token}`
3. 错误处理：全局错误提示（ElMessage）
4. 文件上传：multipart/form-data格式
5. 下载：Blob + URL.createObjectURL
