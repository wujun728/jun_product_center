```vue
<el-button v-clipboard="text">复制</el-button>
<el-button v-clipboard:cut="text">剪切</el-button>
<el-button v-clipboard="text" v-clipboard:success="onSuccess">复制</el-button>
```

```vue

<el-dialog v-dialogDragHeight>可调整高度</el-dialog>
```

#### v-adaptive (表格自适应)
```vue
<el-table v-adaptive="{bottomOffset: 30}" height="100px">
```
